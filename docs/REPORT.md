# Отчёт — v0.1 Practice vertical slice (26.11.2026)

## Сделано по CLAUDE_TASK.md

1. **Движок правил и RNG, тесты первыми.** `rules.ts` — чистые функции, иммутабельное состояние, типизированные ошибки (`WRONG_PHASE`, `NOT_YOUR_TURN`, `STALE_ROLL`, `INVALID_DICE`). Каждый бросок обязан предъявить текущий `rollId` → дубль/устаревший запрос отклоняется. RNG внедряемый: Web Crypto с rejection sampling в игре, seeded/scripted в тестах, без fallback на Math.random.
2. **Контроллер практики.** Чередование шутера, 3 раунда, бот бросает через 800 мс, ввод заблокирован пока кубики летят. Результат определяется в момент нажатия, анимация только показывает его; если сцена не ответила — safety-коммит. Пауза (скрытая вкладка, открытые правила) останавливает таймеры, при возобновлении коммитит те же кубики. Выход с экрана уничтожает контроллер и таймеры.
3. **HUD + Phaser.** React — навигация и HUD (счёт, раунд, пойнт-шайба, подсветка шутера, баннеры, статус-подсказка, большая кнопка, правила, итоги). Phaser — фон, два персонажа, площадка, кубики красный/слоновая кость, дуга броска, пыль. Рендер в DPR (≤2). Арт — оригинальные SVG-заглушки через `assets/manifest.ts`; все $/ставки из мокапов убраны.
4. **Telegram-мост.** ready/expand, цвета шапки/фона, запрет свайпа, safe area из Telegram 8.0 → CSS-переменные, BackButton, haptics. В браузере — fallback на `env(safe-area-inset-*)`, SDK не загружается. Токенов и секретов нет; `initDataUnsafe` используется только как подсказка языка.
5. **Проверки.** test 104/104, build ok, Playwright-смоук полного матча на 360×640 и 390×844 — см. `QA.md`.

## Решения, принятые по ходу (на утверждение)

- **D-01 Первый шутер — игрок**, порядок шутеров 1-2-1. Преимущества почти нет: шутер выигрывает раунд с вероятностью ≈ 49.3%.
- **D-02 Ничья при 3 раундах невозможна** (каждый раунд даёт +100 ровно одному). Логика ничьей реализована и протестирована для чётного числа раундов.
- **D-03 Переход между раундами — по кнопке «Дальше»**, без автоперехода (опция `roundEndHoldMs` есть в контроллере).
- **D-04 Имена персонажей** — Ace (игрок) и Big Lou (бот), вымышленные. Интерфейс RU/EN по языку Telegram/браузера.
- **D-05 Phaser 3.90** (по TECH.md), а не 4.x.
- **D-06 Шрифты** Oswald (кириллица) + Permanent Marker (логотип), упакованы локально, без хотлинков.
