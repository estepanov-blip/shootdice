## Анимации «Animated Graphic Novel» (привязаны к существующим событиям)

| Событие (было) | Визуал (стало) |
|---|---|
| смена экрана | комикс-панель: диагональная шторка + чернильная вспышка с растром |
| покой | «дыхание» персонажей, прожектор над шутером, не-шутер приглушён |
| `rolling` начался | THROW: шутер делает замах и выпад (твин на idle), кубики летят по дуге со «следом», увеличиваются в воздухе |
| кубики приземлились (`onLanded`) | сплющивание, пыль, вспышка-звезда, лёгкая тряска камеры |
| пойнт установлен | бумажная плашка POINT SET + «Пойнт: N», шайба ON поворачивается |
| раунд решён (`roundEnd`) | граффити WIN!/LOSE! на звезде-вспышке; VICTORY — подскок победителя с золотой звездой, DEFEAT — проседание и дрожь проигравшего |
| матч окончен | окно итогов: аватары VS, корона у победителя, проигравший в ч/б |
| твой ход | жёлтый стикер «ТВОЙ ХОД» над кнопкой, кнопка «пульсирует» |
| вызов / принятие | VS-въезд аватаров |

`prefers-reduced-motion` — всё сводится к коротким появлениям, результат тот же.

## ⚠️ Замечания к арту (нужно решение арт-директора)

1. **Знаки, похожие на бренды.** На кроссовках Killa Tee (idle) — знак, похожий на «свуш» Nike; на ботинках Big Roc — круглая эмблема как у Timberland. ART.md запрещает бренды. В билде оставлено как есть (арт не редактировал) — рекомендую перерисовать в следующей версии ассетов.
2. **Big Roc в экшн-раскадровке** — неверный костюм (бандана/майка/штаны), как и отмечено в пакете. Не используется.
3. **Разрешение фонов 540×960** — на экранах с DPR 2–3 заметно мягче персонажей. Для релиза нужны 1080×1920.
4. Мокапы показывают валюту, ставки, XP, лидерборды, «автобой», чат-реакции — **не добавлено** (запрещено GDD / не входит в задачу).

## Вес

Новые картинки ≈ 0,7 МБ (3 фона 458 КБ, 2 персонажа 153 КБ, 2 аватара 42 КБ, 12 кубиков 17 КБ) + шрифт Rubik Dirt ≈ 0,5 МБ (латиница 310 КБ + кириллица 200 КБ, грузятся по unicode-range). Первая загрузка ≈ 1,8 МБ — в пределах лимита 5 МБ. Шрифт — первый кандидат на облегчение (сабсет только используемых глифов).
