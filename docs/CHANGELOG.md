# Changelog

## v0.3.0 — 2026-11-26 — арт-пакет v1.0 (только визуал)
- Фоны The Block / Corner Store / Underground, персонажи Killa Tee и Big Roc (idle + аватары), кубики PNG (красные — твои, слоновая кость — соперника).
- Интерфейс в стиле графической новеллы: рваные кнопки, панели игроков с аватарами, шайба пойнта, граффити WIN!/LOSE!, POINT SET, стикер «Твой ход», VS-экран вызова, комикс-переходы.
- Анимации на idle: дыхание, выпад при броске, след и удар кубиков, тряска, победа/поражение.
- Бот-соперник переименован Big Lou → Big Roc. Механика, сеть и функциональность без изменений.
- Отчёт и список недостающих ассетов: docs/ART_INTEGRATION.md.

## v0.2.0 — 2026-11-26 — дуэли с друзьями
- PvP по схеме Dog Fight: «Вызвать друга» (карточка в чат), принятие, жребий первого шутера, броски по очереди.
- Сервер на Cloudflare Worker + Durable Object: кубики генерирует сервер, проверка подписи initData, идемпотентные броски.
- Бот: «вызов принят», «теперь бросаешь ты», напоминания 1 ч / 12 ч, итог, реванш; /start с кнопкой «Играть».
- Таймаут 24 ч на бросок → техническое поражение. Сдача. Реванш общий для обоих (первым бросает проигравший).
- «Мои дуэли» и «Чемпион чата» (неделя / всё время) для игр из группы.
- Общий HUD для тренировки и дуэли; клиент проигрывает чужие броски той же анимацией.
- Тесты: 128 unit, API e2e 29/29, UI e2e двумя браузерами.

## v0.1.0 — 2026-11-26
- Офлайн-тренировка против бота Big Lou: 3 раунда, уличный крэпс, очки +100 за раунд.
- Чистый движок правил, внедряемый RNG (Web Crypto), контроллер с блокировкой анимации и паузой без переброса.
- Phaser 3 сцена и React HUD, RU/EN, правила, итоги, «Ещё раз».
- Telegram-мост с браузерным fallback.
- Оригинальные SVG-заглушки арта, манифест ассетов.
- Vitest 104 теста, Playwright-смоук, конфиг Cloudflare Workers.
