# Changelog

## v0.2.0 — 2026-11-26 — дуэли с друзьями
- PvP по схеме Dog Fight: «Вызвать друга» (карточка в чат), принятие, жребий первого шутера, броски по очереди.
- Сервер на Cloudflare Worker + Durable Object: кубики генерирует сервер, проверка подписи initData, идемпотентные броски.
- Бот: «вызов принят», «теперь бросаешь ты», напоминания 1 ч / 12 ч, итог, реванш; /start с кнопкой «Играть».
- Таймаут 24 ч на бросок → техническое поражение. Сдача. Реванш общий для обоих (первым бросает проигравший).
- «Мои дуэли» и «Чемпион чата» (неделя / всё время) для игр из группы.
- Общий HUD для тренировки и дуэли; клиент проигрывает чужие броски той же анимацией.
- Тесты: 128 unit, API e2e 29/29, UI e2e двумя браузерами.
